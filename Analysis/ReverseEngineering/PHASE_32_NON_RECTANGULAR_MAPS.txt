# Phase 32 — Non-rectangular board masks

## Scope
The board loader previously initialized every width x height slot as active, which forced every level into a full rectangle. The adapter now preserves missing cells from level data.

## Data support
- `OriginalLevelDefinition.active` accepts an optional bool mask in native `x + width*y` ordering.
- When the mask is omitted, tile id `0` is treated as a missing cell for compatibility with compact level layouts.
- Inactive cells must use tile id `0`; they remain empty and cannot host obstacles.

## Runtime behavior
`Active` is applied before the initial fill. Match scans, swaps, special targets, gravity blockers, cross-falls, refills, column loading, wall grouping and obstacle placement all respect the mask. Rendering and pointer input already skip inactive cells.
