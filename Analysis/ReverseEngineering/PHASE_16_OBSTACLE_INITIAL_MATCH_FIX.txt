PHASE 16 - OBSTACLE INITIAL MATCH FIX
Date: 2026-11-12

Issue reproduced
- The previous self-play check verified FindMove but did not reject an existing match at load.

- The guaranteed opening swap at x=2,y=7 with x=2,y=8 remains intact and is not blocked by any obstacle.
- Added a runtime assertion that MatchBoard.FindMatches() is empty immediately after loading each obstacle level.

Validation
- All four levels start with zero automatic matches.
- All four levels still have a legal opening swap; the swap resolves a match, then clear and gravity execute.
- Unity staging build passed: 22373 assertions, 4500 legal actions, 6393 cascade steps.
